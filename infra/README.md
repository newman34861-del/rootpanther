# infra

Terraform for the API plane: the database, the container that serves `api.rootpanther.com`,
artifact storage, and the private endpoints that make them reachable only from inside the
control network.

This stack does not own the control plane. The Key Vault, Log Analytics workspace and
virtual network are created by the `control-plane` stack in the builder's tree, and are
read here through `terraform_remote_state`, so there is one definition of each.

## What it fixes

The vault was created with public network access disabled and no private endpoint, which
left its data plane unreachable from anywhere. Nothing could store or read a secret. This
stack adds the endpoint and the private DNS zone that resolves it.

## Layout inside the control VNet (10.80.0.0/16)

| Subnet | CIDR | Purpose |
|---|---|---|
| snet-management | 10.80.0.0/24 | existing, owned by the control-plane stack |
| snet-privatelink | 10.80.1.0/24 | private endpoints for the vault and storage |
| snet-postgres | 10.80.2.0/24 | delegated to the flexible server, nothing else may share it |
| snet-apps | 10.80.4.0/23 | Container Apps infrastructure subnet |

## Applying

Requires the platform service principal and the subscription id. Plan first and read it.

    export TF_VAR_subscription_id=...
    terraform init
    terraform plan -out tfplan
    terraform apply tfplan

## Notes

- The database has **no public endpoint**. Migrations run from inside the network, or
  through a jump path, not from a laptop.
- The admin password is generated by Terraform and written to the vault. The API does not
  use it: the migration creates a restricted role, and the API connects as that role so
  row-level security cannot be bypassed.
- Shared storage keys are disabled. The API authenticates with its managed identity.
- The API container scales to zero. Cost tracks use rather than uptime.
- `api_image` defaults to a placeholder so the stack can be applied before a registry
  exists. The deploy pipeline rolls the real image, and this stack ignores changes to it.
